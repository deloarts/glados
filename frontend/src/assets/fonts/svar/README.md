# SVAR wx-icons

The icon font of the SVAR Vue Gantt (`@svar-ui/vue-gantt` 2.8.1, `@svar-ui/vue-core` 2.6.1). The
gantt's `Willow` and `WillowDark` themes link these files from `https://cdn.svar.dev/fonts/wxi/` by
default. `AppGanttChart.vue` turns that off with `:fonts="false"` and imports `wx-icons.css` from
here, so no user's browser contacts a third-party server.

- Source: `https://cdn.svar.dev/fonts/wxi/wx-icons.css`, `wx-icons.woff2` and `wx-icons.woff`
  (cache key `5c1d2b451b95eb4894fd97b9270b27ad`, `Last-Modified` 2026-09-24), downloaded 2026-11-04.
- Changes: the `@font-face` sources point at the local files, woff2 first. The rest of the
  stylesheet and both font files are unchanged.
- License: MIT, as part of the SVAR component library. SVAR stated this for the CDN font files on
  its forum (`https://forum.svar.dev/d/282`, 2026-05-07) together with instructions to self-host
  them. The font files carry no license text of their own (their name table says "Generated by
  svg2ttf from Fontello project"). The library's license follows.

The gantt's text font is not vendored. The themes would load Open Sans from the same CDN, but the
gantt uses the app's body font instead (`--wx-font-family` in `AppGanttChart.vue`).
